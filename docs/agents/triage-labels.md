# Triage Label Vocabulary

Canonical triage labels used by the `triage` skill:

- `needs-triage`: Newly filed issues needing evaluation.
- `needs-info`: Blocked on user clarification.
- `ready-for-agent`: Approved and ready for automated agent implementation.
- `ready-for-human`: Requires human review or manual action.
- `wontfix`: Closed without action.
